# Development Guide

## Prerequisites

- Python 3.10+ (required)
- REAPER 6.x or 7.x (target DAW)
- A functioning brain (v1.0.0 or higher)

## Local Setup

1. Clone the repository.
2. Run `python install.py` and follow prompts.
3. Config templates live in `config_templates/`.

## Useful Commands

- `python install.py`: Run the interactive installer.
- `python install.py --dry-run`: Validate without writing files.
- `python scripts/create_splash_banner.py`: Regenerate splash assets.
